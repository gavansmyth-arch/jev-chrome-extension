Jev options

TypeSafe (required)

Jev is TypeSafe's decision model. Get a key at console.typesafe.ai/keys. It stays in this browser and is sent only to the endpoint below.

Typing text

Jev only chooses; it doesn't write. When a step needs text, Jev first uses anything in quotes in your goal. Otherwise:

Pick a provider to fill in its URL and a suggested model, then paste that provider's own API key (from their website, not from TypeSafe). For a private or self-hosted server choose the last option and enter its URL, model name and key (leave the key blank if the server doesn't use one).

Driving

0 = never ask (default). Try 0.3 if you'd like Jev to check with you when it's unsure. Applies to Run, not Step.
